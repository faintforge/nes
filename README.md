# NES Emulator

For fun attempt at an NES emulator implemented in C99 purely from spec.

## Rules
1. NO LOOKING AT OTHERS CODE
2. NO LLMs
3. Only libraries allowed are libc + SDL (graphics + sound) and stuff I've
written previously.
